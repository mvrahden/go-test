# gotest

> {{ .Site.Params.tagline }}

gotest is a code-generation framework for Go test suites: you write `*TestSuite` structs with lifecycle methods, and `go tool gotest` generates the harness. Run it via Go's tool directive (`go get -tool github.com/mvrahden/go-test/cmd/gotest@<version>`, then `go tool gotest`), never a global binary. `go test` alone does not run suites.
